# Proto Design System (LF Editor Studio V1)

This document preserves the original high-fidelity design system before the Apple Design migration.

## Core Identity
- **Style**: Vibrant Dark Mode, Glassmorphism, Neon Accents.
- **Primary Color**: #6366f1 (Indigo/Primary).
- **Accent Color**: #00e5ff (Cyan/Neon).
- **Secondary Color**: #fb7185 (Rose/Data).
- **Aesthetics**: Heavy use of gradients, backdrop-blur, and glowing shadows.

## Typography
- **Main Font**: 'Inter', sans-serif.
- **Headlines**: Semi-bold to Bold (600-700), standard tracking.
- **Body**: 14px to 15px.

## UI Components
- **Buttons**: Pill-shaped (26px height), bold colors, 입체적 반응 (hover: translateY(-2px)).
- **Cards**: Soft borders with translucent backgrounds.
- **Icons**: Sprite-based legacy system + SVG Atoms (1.6px stroke-width).

## Layout
- **Canvas**: 1440x900 fixed.
- **Sidebar**: Dark panels with blur and border separators.
