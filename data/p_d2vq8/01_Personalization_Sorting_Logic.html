[기획전] 상품표현카드 개인화 상품 정렬 로직 설계

핵심 전략 : 카드 등록 상품 대상 ① [관심상품 ML 100개] 우선 매칭 추출(1순위) ➔ ② [ES 실시간 개인화] 미매칭 잔여상품 랭킹 정렬(2순위) 결합 노출

1. 개인화 (관심상품) 로직| 관리: Data Innovation BSU (머신러닝 기반)

• 데이터 생성 방식 (머신러닝 기반 Daily Batch)

고객 클릭 상품, 구매 기록, 선호도 특성을 종합 분석하여 매일(1일 1회) 배치로 머신러닝 데이터 생성

• 데이터 구조 스키마 (고객 1명 / 상품 100개 단일 String)

고객 1명당 추천 상품코드 100개가 단일 콤마 구분자 String 문자열로 한 줄 적재되는 초경량 구조

데이터 예시 : JLSO6F601W2, WHTS5B901W2, AABA6F280IV, TFSO5D201N1, HATS6C100BK... (총 100개)

• 기획전 상품표현카드 적용 역할 (1순위 우선순위 부여)

카드에 설정된 등록 상품 목록과 고객의 관심상품 100개 리스트를 대조하여, 일치(매칭)하는 상품을 우선 추출하여 최상단 1순위로 배치

2. 개인화 (직접설정) 로직| 관리: e커머스개발실 (Elastic Search 기반)

• Step 1. [배치] 데이터 전처리 및 속성 Combo 필드 생성

상품의 메타 정보(브랜드 / 카테고리 / 시즌 / 성별 등)를 유기적으로 조합하여 피처(Feature)화하고 ES 인덱스에 사전 스코어링

• Step 2. [실시간] 검색 및 매칭 3단계 프로세스

① 유저 니즈 파악 : 고객의 '최근 클릭 상품' 정보를 바탕으로 속성 Combo 필드 조회 후 수치화

② 타겟 그룹 매칭 : 상품 행동 실적을 기반으로 고객의 성별/연령대 세그먼트 정밀 추정

③ 최종 랭킹 노출 : 계산된 유저 니즈 + 타겟 그룹 결합 ➔ 최종 점수화(Scoring) 순서 노출

• 기획전 상품표현카드 적용 역할 (2순위 실시간 랭킹 정렬)

1번 로직에서 매칭되지 않은 나머지 상품들을 대상으로 2번 ES 실시간 개인화 로직을 적용하여 최적의 관심 순서대로 나열

[통합 실행 파이프라인] 기획전 - 상품표현카드 개인화 상품 정렬 순서 결정 흐름도

INPUT

• 타겟 그룹 가중치 (성별/연령 세그먼트)
