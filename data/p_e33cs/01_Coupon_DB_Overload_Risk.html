DB CPU 100% & 커넥션 풀 고갈 ➔ LFmall 전체 서비스 연쇄 장애
💥 1. As-Is 프로세스 주요 문제점
① 실시간 Heavy Query 실행 (Heavy JOIN Query)
고객이 '쿠폰 다운로드' 버튼을 누를 때마다 `MEMBER_MST`와 대용량 `ORDER_HIST` 테이블을 실시간 SQL JOIN 및 SUM 집계하여 DB 응답 시간이 급격히 지연됩니다.
② DB Connection Pool 직격타 (Connection Exhaustion)
기획전 오픈 시 동시 접속자가 폭주하여 초당 수천 건 이상의 요청이 유입될 때, 모든 요청이 회원 DB에 직접 몰려 DB 커넥션 풀이 수초 내 고갈됩니다.
③ Full Table Scan 스파이크 위험
회원 수 및 과거 주문 데이터 누적으로 인덱스 유효범위를 초과할 경우 Full Table Scan 발생으로 DB CPU/IOPS 100% 락업을 유발합니다.
🚨 2. 시스템 영향도 및 장애 리스크
① 쿠폰 발급 실패 및 화면 프리징
API Timeout 발생으로 인해 정작 쿠폰 대상 고객이 쿠폰을 다운로드받지 못하고, 화면 로딩이 무한 멈춤(Freezing)되는 심각한 UX 저하가 발생합니다.
② 회원 DB 공유 서비스 2차 연쇄 마비
동일한 회원 DB를 참조하는 **로그인, 마이페이지, 장바구니, 주문/결제 서비스**까지 DB 커넥션 대기로 인해 연쇄적으로 마비(Cascading Failure)됩니다.
③ 플랫폼 전체 다운타임 (Platform Outage)
단일 기획전 프로모션 이벤트의 부하가 LFmall 전체 플랫폼의 락업(Lock-Up) 장애로 확산될 수 있는 구조적 위험을 안고 있습니다.
