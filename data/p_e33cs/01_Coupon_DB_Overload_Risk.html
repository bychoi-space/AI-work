1. 주요 발생 원인 (Root Cause)
• 쿠폰 클릭 시점마다 회원 구매내역(ORDER_HIST) 테이블 실시간 집계 쿼리 수행
• 대용량 결제 데이터 대상 JOIN 및 SUM 연산으로 쿼리 응답 시간 지연 (Latency > 3,000ms)
• 인덱스 유효범위 초과 시 Full Table Scan 발생
💥
2. 우려 사항 및 영향도 (Risk Impact)
• 초당 10,000건 이상의 동시 요청 시 DB 커넥션 풀(HikariCP) 고갈
• DB 슬로우 쿼리 누적으로 인한 웹/앱 API 서버 쓰레드 락(Thread Lock)
• 기획전 외 LFmall 전체 서비스(로그인, 주문, 결제) 연쇄 다운타임
💡
3. 권장 개선 방안 (Recommended Solutions)
• [방안 1] In-Memory 캐시(Redis) 활용 : 회원별 쿠폰 다운로드 자격 여부 사전 캐싱 (TTL 설정)
• [방안 2] 요약 테이블(Summary Table) 사전 배치 집계 : 전날 자정 배치로 구매실적 등급표 사전 생성
• [방안 3] Kafka/MQ 비동기 쿠폰 발급 : 대기열 메세지 큐 도입으로 DB 직접 조회 차단
