🚀 1. RDBMS 무부하(Zero DB Load) & 시스템 안정성
① 주문 DB Direct Access 100% 차단
쿠폰 다운로드 자격 검증 시 주문 DB로 SQL Query를 전혀 날리지 않고 In-Memory Redis 캐시에서만 조회하므로 DB CPU usage 0% 수준 유지.
② LFmall 타 서비스 연쇄 장애 완벽 방어
기획전 선착순 이벤트 시 초당 10,000건 이상의 클릭 폭주가 발생해도 DB 커넥션 풀이 영향을 받지 않아 로그인, 마이페이지, 주문/결제 서비스 100% 정상 작동.
③ 무제한 수평 확장성 (Horizontal Scalability)
Redis Cluster 구조를 활용하여 향후 대형 프로모션 트래픽(TPS 100k+) 유입 시에도 Redis 노드만 유연하게 확장하여 즉시 대응 가능.
⚡ 2. 초고속 처리 & 이중 배치(Dual Batch) 동기화
① 1ms 미만 초고속 응답 (Sub-millisecond Latency)
RDBMS 대용량 `ORDER_HIST` JOIN 쿼리 대신 Redis 메모리 Key-Value 직접 접근으로 조회 속도를 3,000ms ➔ 1ms 미만으로 약 3,000배 개선.
② 일단위 Bulk + 5분 Incremental 배치 정합성
매일 자정 **일 단위 전체 벌크 적재**로 전체 회원 데이터 정합성을 보장하고, **5분 주기 증분 배치**로 방금 구매한 고객 내역도 준실시간 반영.
③ 장애 격리 (Fault Isolation)
주문 DB에 순간적인 슬로우 쿼리나 장애가 발생하더라도, 쿠폰 다운로드 서비스는 Redis 독립 저장소를 참조하므로 이벤트 서비스가 중단 없이 유지.
