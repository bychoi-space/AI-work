브랜드 첫구매 쿠폰 데이터 & 운영 정책

운영 정책 요약 : Redis Key(회원ID)-Value(구매 브랜드코드 Set) 데이터 구조, 정상 주문완료 시 반영 & 반품 시 구매 제외, 주문 취소 시 쿠폰 자동 복원

POLICY 01
1. Redis 데이터 구조 (Data Schema)
• KEY (키값) : USER_ID (회원 아이디)
• VALUE (벨류값) : Set<BRAND_CODE> (구매이력 존재 브랜드)
• 적재 예시 :
  [홍길동] ➔ ['닥스 여성', '헤지스 남성', '질스튜어트 ACC']
• 특징 : In-Memory Set 구조로 빠른 O(1) 브랜드 보유 여부 검증
POLICY 02
2. 데이터 연동 및 반품 처리 기준
• 정상 연동 기준 : '정상 주문완료' 상태 주문건만 구매 실적으로 인정하여 Redis에 반영
• 반품 처리 예외 정책 :
  - '반품 접수' 및 '반품 완료' 발생 시 해당 브랜드 구매여부에서 즉시 제외/차감
  - 반품 완료 시 해당 브랜드의 첫구매 쿠폰 발급 자격 자동 회복
POLICY 03
3. 주문 취소 시 쿠폰 자동 복원 정책
• 쿠폰 사용 주문 : 브랜드 첫구매 쿠폰을 적용하여 상품 결제 진행
• 주문 취소 시 쿠폰 복구 :
  - 고객이 첫구매 쿠폰 사용하여 주문 후 '주문 취소' 시
  - 사용한 브랜드 첫구매 쿠폰 즉시 자동 복원 (Auto Reissue)
  - 고객 쿠폰함으로 복구되어 해당 브랜드 재구매 시 활용
Redis 데이터 적재 예시 (Key-Value Schema)
KEY (회원 ID) VALUE (구매이력 브랜드 코드 Set) 첫구매 쿠폰 대상 여부
USER_001
(홍길동)		 닥스 여성 헤지스 남성
질스튜어트 ACC 바네사브루노 ACC 		상기 4개 브랜드 불가
USER_002
(이순신)		 헤지스 남성 헤지스 남성 외 가능
USER_003
(강감찬)		 Set { Empty } (구매이력 없음) 전 브랜드 첫구매 가능
Redis 조회 방식 : 쿠폰 다운로드 시 SISMEMBER user:brand:USER_001 DAKS_W 쿼리를 수행하여 빠른 발급 가능 여부 판단
주문/반품/취소 상태별 쿠폰 처리 매트릭스
이벤트 / 주문 상태 구매 브랜드 실적 반영 첫구매 쿠폰 상태
① 정상 주문 완료 Redis Set에 구매 브랜드 추가 연동 해당 브랜드 첫구매 제외
② 반품 접수 / 완료 Redis Set에서 해당 브랜드 차감/제외 첫구매 자격 자동 회복
③ 첫구매 쿠폰 적용 결제 첫구매 할인 쿠폰 적용 사용 처리 쿠폰 사용 완료 (Used)
④ 쿠폰 적용 주문 취소 구매 실적 미반영 (주문 취소건 제외) 쿠폰 자동 복원 (Reissued)
고객 혜택 보호 : 주문 취소 시 사용되었던 브랜드 첫구매 쿠폰이 즉시 복구되므로, 고객 불만 없이 재다운로드/재사용 가능하도록 예외 처리 보장
